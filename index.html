Deep-learning image steganography

Oct 2025 – Jan 2026

Hiding one image inside another so that no one can tell it's there.

  • Designed an adversarial encoder–decoder–discriminator network with U-Net-style skip connections, residual blocks and squeeze-and-excitation attention.
